# 🐾 SNZ Shelter — сайт приюта для животных

Полноценный веб-сайт для приюта «Друг из приюта», написанный с нуля на Django.
Проект отображает животных, ведёт блог с полезными статьями, а также содержит расширенную админ-панель для сотрудников приюта.

Сайт работоспособен и задеплоен на сервер. Его можно найти по адресу [https://drugizpriyuta.ru/](https://drugizpriyuta.ru/)

## 🛠️ Технологии

Backend:

- Python 3

- Django (с чистыми Django Templates)

Frontend:

- HTML5

- CSS (без фреймворков)

База данных:

- PostgreSQL

- База данных бэкапится автоматически раз в неделю или при перезапуске, файлы старше месяца удаляются

- Все упаковано в контейнеры с использованием Docker

- Настроен Nginx, получены и автоматически обновляются сертификаты Let's Encrypt


Проект создан как рабочий сайт реального приюта.


# ✨ Основной функционал
## 👇 Публичная часть сайта

- 📄 Каталог животных с краткими карточками, животные ранжируются по группам в зависимости от перспективности и псевдослучайно (в зависимости от даты) - внутри своей группы.

- 🐶 Страница животного — полная информация (история, особенности, фото)

- 📝 Блог / статьи — полезные материалы о животных, уходе и пристройстве. Пишу понемножку.

- 🔍 Фильтрация животных по полу, возрасту, в случае собак - по росту (в процессе)

- 🪙 Финансовая отчетность
